# ШУЭ-Тренажёр

Учебный Android-симулятор шкафа управления электролизом.

## Статус
Версия 0.1.3 — ранний прототип, не цифровой двойник оборудования. Есть 15 кодов отказов по предоставленной таблице, условная модель KA1 и черновой список узлов шкафа.

## Сборка на телефоне
Откройте GitHub → Actions → Build Android APK → Run workflow. После успешной сборки скачайте артефакт shue-trainer-debug-apk из страницы запуска и извлеките APK из ZIP.

## Безопасность
Учебная модель не предназначена для управления промышленным оборудованием. Показания виртуальных измерений условные.

## Дальнейшая работа
Точная визуализация лицевой панели, интерактивные зоны, проверенные соединения, полноценные сценарии отказов, обновления контента.
